# 포켓 수학 모험 (로컬 웹 프로토타입)

5~8살을 위한 수학 문제 풀이형 포획 게임입니다. 서버 없이 `index.html`을 브라우저로 열면 됩니다.

## 실행
- `index.html`을 Chrome 또는 Edge로 엽니다 (더블클릭).
- 음성 읽어주기(speechSynthesis)는 브라우저 설정에 따라 한국어 음성이 없을 수 있습니다.

## 게임 흐름
1. 나이(5~8살)를 고릅니다. 나이에 따라 문제 종류가 바뀝니다.
2. "풀숲 걷기"로 포켓몬을 만납니다. 포켓몬 희귀도(tier)에 따라 문제가 어려워집니다.
3. 정답을 맞히면 마음 게이지가 줄어듭니다. 오답 2번이면 도망갑니다.
4. 게이지가 0이 되면 볼을 고릅니다. 연속 정답이 5개면 그레이트볼, 10개면 울트라볼을 씁니다.
5. 잡으면 도감에 등록되고, 도감에서 진행 상황을 볼 수 있습니다.

| 나이 | 문제 |
|---|---|
| 5살 | 그림 세기 (사과 개수 맞히기) |
| 6살 | 10 안의 덧셈·뺄셈 |
| 7살 | 20 안팎의 덧셈·뺄셈 |
| 8살 | 구구단 곱셈, 일부 나눗셈 |

## 구조
```
game/
├─ index.html      진입점
├─ style.css       스타일 (밝은/어두운 테마)
├─ app.js          게임 로직 (문제 생성, 포획, 도감, 저장)
└─ assets/
   ├─ ui/          볼·별·버튼 이미지 (APK의 Unity 어셋에서 추출)
   ├─ sfx/         효과음 (APK의 Unity 어셋에서 추출)
   └─ pokemon/     포켓몬 이미지 (PokeAPI 공식 아트워크)
```

## 주의: 어셋 사용 범위
- 이 폴더의 `assets/`는 **개인 학습용**입니다. 포켓몬 관련 이미지와 소리는 각 권리자의 저작물입니다.
- 이 게임을 공유하거나 배포하지 마세요. 공개할 때는 `assets/`를 직접 제작하거나 라이선스가 명확한 이미지로 교체해야 합니다.

## 저장
- 진행 기록은 브라우저 `localStorage`에 저장됩니다 (키: `poke-math-v1`).
- 같은 브라우저에서만 유지되며, 도감 화면의 "진행 기록 지우기"로 초기화할 수 있습니다.
